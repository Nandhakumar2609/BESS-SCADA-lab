Project · OT / SCADA engineering · built end to end on Linux

BESS Site SCADA & Data Acquisition Lab

A working SCADA system for a simulated 1 MW / 2 MWh battery storage site: Modbus TCP field devices built from a protocol mapping table, a Python gateway polling them into an InfluxDB historian, Grafana dashboards, and a segmented OT network behind an nftables firewall with WireGuard remote access. Deployed with Ansible and delivered with the commissioning paperwork a real project needs.

What the project delivers

Engineering

  • Coupled physics model: SoC with efficiency, LFP voltage curve, cell imbalance, thermal lags, HVAC hysteresis, transformer losses
  • Block-read poller with comms and heartbeat watchdogs, store-and-forward to the historian
  • Alarm engine with deadband, on-delay, bitfield expansion and severities; alarm journal and bad-actor list
  • SoC-window dispatch with interlocks and a supervised fault-reset limit (3 per hour)

Infrastructure and security

  • VLAN/IP plan, routing, DNAT/SNAT, default-deny nftables rendered from one zone model
  • WireGuard with engineer and viewer roles, split tunnel
  • Host hardening mapped to IEC 62443-3-3: SSH, sysctl, auditd, journald, host firewall, unprivileged read-only containers, least-privilege tokens
  • Ansible roles: common, hardening, docker, stack, wireguard, backup

Commissioning paperwork

  • FAT and SAT checklists with sign-off tables; automated FAT report
  • Topology diagram, IP plan, register map and alarm list generated from configuration
  • Backup and restore with SHA-256 manifests; configuration baseline with daily drift check
  • Operations runbook and troubleshooting guide
The field devices are simulated; the protocol, encoding, network and software are real and run on any Linux host with Docker. Security design follows IEC 62443 concepts and is not a certified implementation.
